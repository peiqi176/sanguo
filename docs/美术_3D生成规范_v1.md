# 美术 3D 模型生成规范 v1

> 适用项目：《三分天下·再起》
> 依据：`scripts/core/GridManager.gd`（cell_size = 2.0）、`docs/美术锚点规范_v1.md`（兵高 1.86m / 官府 6.9m）
> 建立日期：2026-10-28

---

## 一、统一基准（所有模型强制执行）

| 基准项 | 值 | 说明 |
|---|---|---|
| 1 格 | 2.0 米 | 建筑底座 = 格数 × 2m |
| 士兵身高 | 1.86 米 | 与现有精灵素材对齐 |
| 原点 | 脚底 / 底座中心 (0,0,0) | 导出前 Apply Transform |
| 朝向 | 正面朝 **-Z** | Godot 前向，全项目统一 |
| 禁止内容 | 地面、烘焙阴影、背景、文字、边框 | 引擎投真实阴影 |
| 导出格式 | glTF 2.0 (.glb) | 不用 FBX |
| Scale | Apply 后必须为 1.0 | |

---

## 二、工具选型

| 资产类型 | 建议方式 | 理由 |
|---|---|---|
| 建筑（28 座） | 图生 3D（Tripo / Rodin / Meshy / Hunyuan3D）+ 减面 + 重拓扑 | 已有 2.5D 立绘可作参考图，风格天然统一；建筑不需骨骼动画 |
| 树木 / 石头 / 杂物 | 图生 3D 或手搓 + MultiMesh | 面数极低 |
| 城墙段 | **不用 AI**，手工做模块件 | 需严丝合缝拼接，AI 尺寸对不上 |
| 士兵 / 武将 | **慎用 AI**，手工建模 + 共用骨架 | AI 三角面乱拓扑无法绑骨做动画 |
| 攻城器械 | AI 生成 + 手工拆分活动件 | 抛臂需独立运动 |

### 减面流程

1. Quad Remesher 重拓扑（单位必须做，建筑可跳过）
2. Decimate → Planar，角度 5°（建筑专用，直角多，砍 60% 不掉观感）
3. Decimate → Collapse，收敛到目标面数
4. 检查包围盒尺寸，误差 ≤ 2%

### 性能红线

| 项目 | 上限 |
|---|---|
| 材质槽 / 模型 | 1~2（士兵 1） |
| 骨骼数 / 士兵 | ≤ 25 |
| 骨骼数 / 武将 | ≤ 60 |
| 骨骼数 / 坐骑 | ≤ 15 |
| 单兵模型文件 | 同兵种共用一套 rig + 动画库 |

同屏预算核算：200 单位 ×1500 + 60 建筑 ×3000 + 300 树 ×400 + 地形 ≈ 60 万三角面，属安全区间。

## 五、AI 生成提示词骨架

```
中国三国时期 {建筑名}，3/4 俯视视角，正面朝向镜头，
干净半写实风格（帝国时代4 质感），木构架 + 青瓦顶，
正面可见 + 右侧面可见，无地面、无阴影、无边框、无文字，
单色中性背景，居中等比
```

要点：
- 必须体现"正面 + 右侧面"，相机为俯角 45°、偏航 45°
- 主光方向 `SUN_EULER_DEG = (-55°, 45°, 0)`，左上受光、右下背光
- 允许画水平台基（用于压住地形接缝），禁止落地阴影

## 六、单位模型硬约束

| 项 | 要求 |
|---|---|
| 姿态 | A-Pose（手臂下垂 30~40°），禁止 T-Pose |
| 拓扑 | 四边面重拓扑，三角面乱拓扑不可绑骨 |
| 骨架 | 士兵共用骨架 ≤25 骨，武将 ≤60 骨 |
| 动画 | 同类兵种共用一套动画库，仅换 mesh |
| 面数 | 士兵 ≤1500 tris（本视角约 60 像素高，超出无收益） |

## 八、排产顺序

1. 样片：民居 + 官府 + 1 个刀兵，跑通生成→减面→导入→上屏，实测 100 兵同屏帧率
2. 定风格：三件并排比对贴图密度与色调，确认后再批量
3. 批量建筑：28 座，约 3 座/天
4. 城墙模块 + 树木 MultiMesh：2 天
5. 单位：29 兵种 + 40 武将，先立骨架与动画库，再换皮
