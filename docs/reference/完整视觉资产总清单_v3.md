### ⚠️ 核心机制（重要！）
**基础兵种全部一套 mesh 颜色参数化，步兵可以骑马变骑兵！**
- 步兵 mesh + 马 = 骑兵（运行时动态组合，不用单独做骑兵 mesh）
- 只有 **4 种精锐骑兵** 需要单独做（因为有独特装备/护甲）
