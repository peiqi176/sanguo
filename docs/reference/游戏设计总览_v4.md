# 一、核心原则（全局规则）

## 【🔥 v4 变更】1.1 属性计算统一基准（加算，非乘算）
- **所有加成/惩罚均基于基础属性做加法**
- 公式：`最终值 = base × (1 + Σ所有加成百分比 - Σ所有惩罚百分比)`
- 例如：武将基础攻速 1.0 → 科技加成 +10%，体力惩罚 -20% → `1.0 × (1 + 0.1 - 0.2) = 0.9`

## 【🔥 v4 变更】1.2 伤害公式（减算，非乘算）

### 普通攻击（无暴击）
```
最终伤害 = (攻击力 × 克制系数) - (敌方防御力 × (1 - 穿甲系数))
```

### 暴击攻击
```
最终伤害 = (攻击力 × 克制系数 × 暴击伤害系数) - (敌方防御力 × (1 - 穿甲系数))
```
- 暴击伤害默认 125%，可被其他加成提升（如关羽·青龙偃月）
- 穿甲系数：不同兵种/技能可提供（斧兵30%、破甲箭25%等）

## 【🔥 v4 变更】1.3 士气→防御挂钩、体力→攻速挂钩

| 属性A | 挂钩属性B | 公式 |
|-------|---------|------|
| 士气 morale | 防御力 defense | 士气100时防御+30%，士气0时防御-10% |
| 体力 stamina | 攻击速度 atk_speed | 体力80+无惩罚，体力0时攻速惩罚30% |

## 1.4 消耗统一
- **士兵消耗以包子为主，无法直接吃肉和谷物**
- 加工链：谷物 → 作坊 → 包子 + 酒
- 鱼肉/猪羊肉 → 生产包子的原料
