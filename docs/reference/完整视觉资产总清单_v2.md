## 六、材质参数化规则（所有兵种）

**核心：一套 mesh，4 势力着色！**

每个兵种模型使用 **3 个材质槽**：

```
材质槽 1：主甲/tunic（用 _BaseColor + tint 参数控制势力颜色）
  曹魏 tint → Color(0.73, 0.23, 0.23) 暗红
  蜀汉 tint → Color(0.31, 0.68, 0.31) 墨绿
  东吴 tint → Color(0.29, 0.50, 0.81) 深蓝
  群雄 tint → Color(0.55, 0.20, 0.55) 暗紫

材质槽 2：武器（不动，金属色）
材质槽 3：配件（皮带/护腕/羽毛，可选 tint）
```

**实现方式：** 每个兵种 `.tscn` 有 4 个变体子场景，或运行时用 `mesh.material_override` 设置 tint 参数。
