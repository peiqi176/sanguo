## 一、底层系统公式（核心代码已实现）

### 1.1 伤害公式（Unit.gd L644-682）
```
基础伤害 = max(1, 攻 × 克制系数 - 有效防御 × (1 - 穿甲))
暴击伤害 = max(1, 攻 × 克制系数 × 暴击倍率 - 有效防御 × (1 - 穿甲))

有效防御 = 目标防御 × 士气防御系数
士气防御系数（smoothstep 分段）：
  士气 0-30%   → 0.85 → 1.0（被克制防御低15%）
  士气 30-70%  → 1.0 → 1.15
  士气 70-100% → 1.15 → 1.30（满士气防御+30%）

穿甲 = armor_pierce（0-1 之间，弩手0.25/重弩0.35/床弩0.5）
克制系数 = 1 + counter_bonus（被克时）
暴击倍率 = 1.25（基础），将领 + 武力加成
```
