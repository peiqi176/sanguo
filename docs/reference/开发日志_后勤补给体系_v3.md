## 一、补给区系统（P1）

### 1.1 补给区两级模型

| 补给点类型 | 补给半径 | 说明 |
|-----------|---------|------|
| **城池** | `max(15, 城墙到官府最远距) + 20格` 外延 | 内城（城墙圈）+外延20格；官府被毁则失效 |
| **仓库（仓廪）** | 12格 | 野外补给点 |
| **营帐** | 12格 | 辎重车扎营后形成（military_camp 建筑） |
| **村庄** | 10/12/14格 | 1/2/3级村庄 |
| **辎重车（移动）** | 6格 | 移动补给点 |

### 1.2 补给区判定逻辑

- **缓存机制**：每0.5秒缓存一次补给区状态（`_update_supply_state`）
- **判定优先级**：城池 > 仓库/营帐 > 辎重车 > 村庄
- **城池半径计算**：`city_radius = max(15, 城墙到官府最远距)`

## 二、士兵体力系统（P1）

### 2.1 体力消耗/恢复

| 状态 | 数值 | 说明 |
|------|------|------|
| **区内恢复** | +5/s | 20秒回满 |
| **区外衰减** | 100→50: 0.278/s（180秒）<br>50→0: 0.417/s（120秒） | 分段衰减 |
| **人海支撑** | 衰减×1.3 | 半径6格友军>20时 |
| **体力0惩罚** | 攻速减半 | `attack_cooldown = (1.0/atk_speed) * 2.0` |

### 2.2 通用消耗

- **区内每单位**：1馒头 + 1酒 / 分钟
- **服务单位>20**：总耗×1.3
- **缺馒头**：体力恢复停止
- **缺酒**：士气恢复停止 + 武将法力回落

### 6.2 人口系统

- **增长速度**：+1/30秒（有粮时）
- **民夫自产**：村庄自产不占主城人口

### 6.3 繁荣度

| 等级 | 所需繁荣度 | 增长速度 |
|------|-----------|---------|
| 1→2 | 300 | +1/分，有任命+2/分 |
| 2→3 | 600 | +1/分，有任命+2/分 |

### 6.4 民心

- **初始值**：50（0-100）
- **民夫被杀**：民心-10，繁荣-20

### 6.5 税收

```
税收 = 人口÷10 × 民心% 金/分钟
```

### 6.6 任命系统

| 职位 | 效果 |
|------|------|
| **文臣** | 民心+0.5/分、产出+10%×内政/100 |
| **武将** | 驻军士气不掉、防御+15%×武力/100 |

### 6.7 中立/盟友村庄买体力

- **价格**：0.5金/兵
- **效果**：+5/s 体力恢复，持续10秒

## 七、运输队系统（P4）

### 7.1 运输队参数

| 项目 | 数值 |
|------|------|
| **HP** | 100 |
| **移动速度** | 1.5 |
| **押运民夫** | 1-5人 |
| **运输资源** | 任意资源（bun/wine/gold等） |

### 7.2 运输流程

1. 玩家选择村庄作为起点
2. 选择目的地（城池/营帐/其他村）
3. 扣除村庄资源和民夫
4. 运输队移动至目的地
5. 交付资源到全局库存
6. 民夫返回村庄

### 7.3 劫掠规则

- **被劫损失**：50%货物被劫方获得
- **民夫死亡**：押运民夫全部死亡，影响村庄民心/繁荣度
