## 四、武将骑马规则（重要！）

```
✅ 可以骑马（所有武将）
   - 默认自带：骑类兵种直接有马（caocao/xuchu/zhaoyun/guanyu/zhouyu...）
   - 手动骑马：步/弓/文臣 可以手动 上/下马
   - 手动骑马方式：选择武将 → 点"上马"按钮（从 stable 分配 horse）

❌ 不可以骑马（纯文臣）
   - xun_yu / xun_you / guo_jia / cheng_yu / wang_lang
   - pang_tong / fa_zheng / ma_liang / xu_shu（徐庶算半骑半文，可骑）
   - lu_su / zhuge_jin / zhang_zhao / zhang_hong
   - liu_biao / liu_zhang / kong_rong / han_fu
   - 所有 civil 默认文臣

例外：
   - 诸葛亮：文官但可以骑马（四轮车改为骑马模型，体现其行军）
   - 徐庶：半骑半文（可以骑马）
   - 庞统：纯文臣（不骑马）
```
