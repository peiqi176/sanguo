# 《三分天下·再起》完整设计方案 v3（定稿）

> 整理日期：2026-10-15
> 玩法参考：《傲世三国之三分天下》（玩法魂）+《帝国时代4》（画面壳）
> 引擎：Godot 4.7.2 / GDScript
> 核心原则：**不硬改数据，改 AI 起跑线、操作速度和发展思路；所有加成封顶，控制 ≤3 秒**

---

## 一、AI 强度档系统（4 档）

### 设计理念
- ❌ 不修改建造速度、训练速度（拒绝纯数值变强）
- ✅ 差距来自：初始资源 + 操作速度（反应延迟）+ 发展思路
- ✅ 所有档位初始建筑一样：**官府 + 牌楼**（招募农夫用）
- ✅ 所有档位决策逻辑相同（都有思路、都会进攻），只比手速
- ✅ 兵种攻击力、农夫产出、建造时间全难度完全相同

### 四档参数

| 档位 | 操作速度（反应延迟） | 初始资源倍率 | 初始农夫 | 战略倾向 |
|------|-------------------|-------------|---------|---------|
| 简单 | 3.0s | 1.0× | 2 | 慢节奏，先稳后扩 |
| 普通 | 2.0s | 1.2× | 3 | 标准 RTS 节奏 |
| 困难 | 1.0s | 1.8× | 4 | 进攻型，抢中立村庄/马厩 |
| 最高难度 | 0.5s | 2.5× | 6 | 超级战争倾向，4 兵营爆兵 |

### 操作速度定义
从"农夫/建筑/兵就绪"到"下一个动作执行"的间隔时间：
- 农夫造出来多久派遣
- 建筑完了多久开下一个
- 战斗中多快调整操作
- 兵营出兵多久编队

### 发展思路（AI 决策逻辑，所有档位共享）
- 前期资源多 → 优先建民居增加农夫上限 → 多招募农夫提升采集
- 资源富余 → 建造多个刀兵营**同时练兵**
- 前期兵力成型 → 占领中立村庄、抢占中立马厩、增加税收
- 困难以上 → 开局快速满农田、3 兵营并行、先派骑兵抢中立

## 二、武将系统

### 2.1 武将分类（纯战斗类型，与四维无关）

| 分类 | 特点 | 代表 |
|------|------|------|
| 猛将 | 高攻+高防，正面硬刚 | 关羽、许褚、典韦 |
| 防御 | 高血量+高防，守城/吸收伤害 | 曹仁、郝昭、程普 |
| 进攻型 | 高攻+高移速，切入后排 | 赵云、张辽、马超 |
| 谋臣 | 高智谋，献策+黑雾看穿，下场打架弱 | 诸葛亮、司马懿、周瑜 |
| 异人 | 技能偏门有独特点 | 吕布（全能怪）、貂蝉（反间）、左慈（仙术） |

> 具体看人物数据：吕布归异人，但个人数据是高攻+高移速+中防。

### 2.2 四维属性（基础 + 成长分离，前期差异 ≤5 点）

| 属性 | 基础范围 | 每级成长 | 满级范围 | 效果 |
|------|---------|---------|---------|------|
| 武力 | 50-85 | +2.0/级 | 66-101 | 单挑伤害、暴击率；加成封顶（60 武力生效上限，总加成 ≤30%） |
| 智谋 | 40-90 | +1.5/级 | 52-102 | 献策几率 = 智谋×0.15%（最高 ~15%，不频繁） |
| 统御 | 45-80 | +1.5/级 | 57-92 | 部队减伤 = 统御×0.15%（封顶 15%） |
| 内政 | 30-95 | +1.0/级 | 38-103 | 任命政务后税收加成（封顶 25%）；**内政只有被动和任命，无主动技能** |

### 2.3 等级与经验（1-9 级）

| 等级 | 到下一级需 XP | 累计 XP | 每级加成 | 天赋点 |
|------|-------------|--------|---------|--------|
| Lv1 | 200 | 0 | 基础值 | - |
| Lv2 | 380 | 200 | 武+2 智+1.5 统+1.5 内+1 | +1 |
| Lv3 | 620 | 580 | 同上 | +1 |
| Lv4 | 920 | 1200 | 同上 | +1 |
| Lv5 | 1300 | 2120 | 同上 | +1 |
| Lv6 | 1800 | 3420 | 同上 | +1 |
| Lv7 | 2450 | 5220 | 同上 | +1 |
| Lv8 | 3300 | 7670 | 同上 | +1 |
| Lv9 | 满 | 10970 | 同上 + **体力自动恢复** | +1 |

- XP 来源：战斗杀敌 + 献策 + 政务任命 + 单挑胜利
- 每级 HP +15，升级瞬间回满
- 天赋点共 9 点，用于升级技能（每技能最多 3 级）

### 2.4 技能双轨制

```
🟢 基础技能（无 CD，消耗 MP）
├── MP 上限 = 80 + 智力×0.3（诸葛亮 MP=110，关羽 MP=80）
├── MP 恢复：脱战 5/秒
└── 控制类技能时间 ≤3 秒

🔴 武将技（有 CD 60-180s，不消耗 MP）
└── 强效果但不 OP
```

### 2.5 技能等级与施法人数（通用规则）

```
Lv1 → 1 人
Lv2 → 2 人（目标 + 旁边连带 1 个友军）
Lv3 → 3 人（目标 + 旁边连带 2 个友军）

施法半径：步行 2.0 / 骑马 2.5
骑马/步行均可释放，无位移冲刺类技能
```

## 六、献策系统（智谋联动）

```
触发条件：战斗中 + 智谋 ≥ 50
几率：智谋 × 0.15%（智80 = 12%，智90 = 13.5%）
冷却：每 30s 最多触发 1 次

效果池：
├── "主公！敌军在 X 处有埋伏！" → 标记敌方部队位置 5s
├── "此时火攻可破敌！" → 下一次己方攻击 +15%
└── "敌军士气低落，正好进攻！" → 敌军士气 -10
```

黑雾模式智谋联动：

| 情况 | 普通玩家 | 智谋≥80 | 智谋≥95 + 治安官 |
|------|---------|---------|-----------------|
| 视野外敌人 | 看不见 | 模糊轮廓 | 精确兵种+HP |
| 敌方调兵 | 看不见 | 提前 15s 路线预告 | 提前 30s + 兵力数量 |
| 敌方来攻 | 进射程才发现 | 10 格外警告 | 15 格外 + 防守方案 |

## 七、单挑系统（可开关）

```
规则：
├── 开局设置可开关（默认关）+ 每个武将可单独开关
├── 两个都开的武将碰面 → 自动进入单挑
├── 头顶 ⚔ 若隐若现图标提示可单挑
├── 时长上限 10 秒
├── 伤害公式：基础 × (1 + 武力差×0.5%)，封顶 ±25%
├── HP 先归 0 的输
├── 输家：HP 剩 20% 强制退出 + 士气 -10
└── 不想单挑的武将关掉开关 → 碰面正常打
```
