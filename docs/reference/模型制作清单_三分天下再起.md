### ⚠️ 武将骑马规则（重要！）
**所有武将都可以骑马（手动骑马），文臣不行！**
- 默认骑：骑类兵种（cavalry_light/heavy/archery + 名将：关羽赵云张辽等）
- 手动骑：步/弓/郎勇名将（张飞/许褚/黄忠/典韦 等可在上马/下马间切换）
- 文臣（❌）：荀彧/郭嘉/庞统/鲁肃/张昭 等（默认不带马）
- 例外：诸葛亮虽为文官但可以骑马（四轮车模型改为骑马版）

## 七、文件清单快速参考

```
config/
├── units.json        ← 兵种 28 个（peasant 改名农夫显示）
├── buildings.json    ← 建筑 31 个（城墙 4 + 门 4 + 核心 4 + 民居 4 + 军事 10 + 功能 3 + 生产 4）
├── generals.json     ← 武将（目前 0 个，要加 30+ 个）
├── tech.json         ← 科技（官府升级 / 城门 HP 升 10000）
└── maps.json         ← 预设地图

scripts/
├── core/
│   ├── Main.gd           ← spawn 流程（读 initial_soldiers/initial_peasants=5）
│   ├── GameManager.gd    ← 初始士兵/农夫/文臣字段 + apply_settings
│   ├── Pathfinder.gd     ← A* 缓存+迭代上限
│   └── DisasterSystem.gd ← 灾祸 8%/月 + 5 种效果（需要写！）
├── entities/
│   ├── Building.gd       ← 农夫指派 / 城池占领逻辑（HP 到 500 停攻 + occupy 判定）
│   ├── Unit.gd           ← HP 每级 +5% 成长（改 _compute_growth）
│   └── ResourceNode.gd   ← 树木再生 + 矿洞归属
├── ui/
│   ├── MainMenu.gd       ← 单页自定义（已重写）
│   └── GameUI.gd         ← 游戏内 HUD
└── ai/
    └── AIController.gd   ← AI 进攻/占领/扩张
```
