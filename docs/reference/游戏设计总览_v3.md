# 一、核心原则（全局规则）

### 【核心原则 1】属性计算统一基准（加算，非乘算）
- **所有加成/惩罚均基于基础属性做加法**
- 公式：`最终值 = base × (1 + Σ所有加成百分比 - Σ所有惩罚百分比)`
- 例如：武将基础攻速 1.0 → 科技加成 +10%，体力惩罚 -20% → `1.0 × (1 + 0.1 - 0.2) = 0.9`
- 科技加成、武将技能、阵型效果、地形效果、体力惩罚等全部加算到同一个括号里

### 【核心原则 2】伤害公式
```
最终伤害 = (攻击力 × 克制系数 × 士气系数 × 暴击系数) - 防御力
```
- 克制系数：参考兵种克制链
- 士气系数：100士气+30%，0士气-10%
- 暴击系数：暴击率触发后 × 暴击伤害

### 【核心原则 3】消耗统一
- 士兵消耗：谷物（粟米）为主，**无法直接吃肉和谷物**
- 加工链：谷物 → 作坊 → 包子 + 酒
- 鱼肉/猪肉/羊肉等 → 生产包子的原料（**后续扩展**）

```
粟米 ──┬──→ 包子（作坊加工，士兵恢复体力）
        │
        ├──→ 酒（作坊加工，耗粟米×3）
        │
        └──→ 招募农夫

肉食/鱼肉 ──→ 生产包子（提升包子产量效率）
```

# 六、体力/士气系统（v3 最新版）

## 6.1 【🔥本次修改】体力影响攻速（**区间曲线函数**）

### 曲线函数定义
```
体力(stamina) → 攻速惩罚系数(penalty_mult)
```

| 体力区间 | 惩罚公式（**线性插值曲线，不是离散分档**） |
|---------|------------------------------------------|
| **80 - 100** | penalty_mult = 0.0（无惩罚） |
| **50 - 80** | penalty_mult = 0.0 → 0.1（体力50时最大10%惩罚） |
| **30 - 50** | penalty_mult = 0.1 → 0.2（体力30时最大20%惩罚） |
| **0 - 30** | penalty_mult = 0.2 → 0.3（体力0时最大30%惩罚） |

### 示例计算
- 体力 90 → 惩罚 0% → 攻速 = base_atk_speed
- 体力 65 → 位于 50-80 区间中点 → 惩罚约 5% → 攻速 = base × 0.95
- 体力 50 → 惩罚 10% → 攻速 = base × 0.90
- 体力 40 → 位于 30-50 区间中点 → 惩罚约 15% → 攻速 = base × 0.85
- 体力 30 → 惩罚 20% → 攻速 = base × 0.80
- 体力 15 → 位于 0-30 区间中点 → 惩罚约 25% → 攻速 = base × 0.75
- 体力 0 → 惩罚 30% → 攻速 = base × 0.70

### 代码实现建议（smoothstep 版）
```gdscript
func stamina_to_speed_penalty(stam: float) -> float:
    # 分段线性插值，区间边界连续
    if stam >= 80.0:
        return 0.0
    elif stam >= 50.0:
        return lerp(0.0, 0.1, (80.0 - stam) / 30.0)
    elif stam >= 30.0:
        return lerp(0.1, 0.2, (50.0 - stam) / 20.0)
    else:
        return lerp(0.2, 0.3, (30.0 - stam) / 30.0)
```
