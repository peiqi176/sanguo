## 1. Fun Hypothesis & Design Pillars

**好玩的核心 =** 在傲世三国式"内政 + 武将养成"底盘上，打一场有规模感、有补给逻辑、名将能左右战局的三国军团 RTS。

**5 条不可妥协的体验支柱（每条后续决策都要过审）：**

| # | 支柱 | 违背时的后果 |
|---|------|------------|
| P1 | **补给即战术**：体力/士气/粮草驱动战斗，不是无脑数值堆 | 变成另一个 AoE 换皮 |
| P2 | **名将差异化**：每个名将一个记忆点技能，不是换皮 | 收集欲崩塌 |
| P3 | **农夫指派经济**：每个建筑要人入岗才产出，有微观操作 | 经济变成挂机收租 |
| P4 | **AI 差距来自手速与思路，不靠数值变强**（4 档难度原则） | 高难=纯数值碾压，无技巧 |
| P5 | **控制有上限**：所有硬控 ≤3s，防一招秒杀 | 单将控全场，节奏断裂 |

## 3. 权威数值表（已裁决）

### 3.1 公式类（无冲突，直接采用）

| 公式 | 取值 |
|------|------|
| 伤害 | `(攻×克制) - 防×(1-穿甲)`，暴击 ×1.25 |
| 士气→防御 | smoothstep：士气 0→30% 时 0.85→1.0；30→70% 时 1.0→1.15；70→100% 时 1.15→1.30 |
| 体力→攻速 | smoothstep 分段：80-100=0、50-80=0→0.1、30-50=0.1→0.2、0-30=0.2→0.3 |
| 武将暴击 | `武力×0.15%`，上限 15% |
| 武将献策 | `智谋×0.15%`，战斗+智谋≥50，CD 30s |
| 统御减伤 | 封顶 15%；内政封顶 25% |
| 武将 MP | `80 + 智谋×0.3`，非战斗 +5/s |
| 士兵经验 | 共用曲线 120→300/exp，杀人 +0.12/杀 软上限 300 |

### 3.2 士兵成长（【待裁决】核心冲突，见第 4 节）

## 7. 风险与张力

- **通胀风险（简评）**：sources（农场/矿洞/税收/市场）已有；sinks 端——包子/酒被战斗消耗、建筑耗木石、招募耗金。目前 **gold 的 sink 偏弱**（除建造/招募外无持续消耗），长期单机局可能 gold 溢出 → 建议后续加"维护费/俸禄"类持续 sink（待设计，不强行现在加）。
- **张力·专注核心 vs 防备通胀**：核心循环没美术也能玩，但 0% 美术会让"名将差异化"（P2）完全失效——美术不是装饰，是 P2 的载体。
- **张力·纸面先验证 vs 数据再调**：D1-D6 必须在改 config 前定，否则"上线后再调"等于没调（本角色红线）。
