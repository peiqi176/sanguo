# 《三分天下·再起》全资产清单与尺寸规划 v1

> 参考：《帝国时代4》《傲世三国之三分天下》
> 尺寸基准：1 格 = 2.0 米；士兵 1.86 米；官府 8.0 米（全图最高）
> 建立日期：2026-10-28
> 本文件与 `美术_3D生产流程_v1.md` 配套使用

## 〇、先分清两类资产（这是最容易走错的一步）

| 类型 | 举例 | 做法 |
|---|---|---|
| **A. 3D 模型资产** | 建筑、单位、树、石头、桥、器械 | 建模 → glb 导入 |
| **B. 非模型资产** | 地表材质、水面、河流、天气、特效 | 地形系统 + Shader + 粒子，**不做模型** |

河流、草地、道路、雪地、沼泽**全部属于 B 类**。用模型做河流是最常见的翻车方式（拼接缝、水位对不齐、寻路穿模）。
