## 二、建筑高度修订表（重点：整体压低）

### 定高原则（必须遵守）

```
总高（地面→屋脊） = 台基 + 柱身 + 屋顶
台基： 民居 0.20 / 公共 0.30 / 官府 0.60
单层柱身：3.0~3.4    双层柱身：5.6
屋顶： 单檐 1.2~1.6   重檐 2.4
```

三条硬约束：

1. **城墙与同档城门必须等高**，否则城门会突兀地矮一截或高出一头
2. **官府（8.0 m）是全图最高**，其它建筑一律不得接近，高度 = 权力暗示
3. 民居不得超过士兵身高的 2.5 倍（≈4.6 m），否则站在旁边像巨人国

## 三、生产流程总览

```
阶段0 锁尺寸表
   ↓
```

## 六、阶段 2：生图（每座 2~3 张）

### 为什么要多张

单张图生成的 3D 模型，**背面和侧面是 AI 编的**，转个镜头就穿帮。多视图输入（Rodin / Meshy 多图模式）能把这个坑填掉大半。

### 每座建筑出图清单

| 图 | 视角 | 用途 |
|---|---|---|
| A 主图 | 俯角 30~35°、偏航 45° 的 3/4 前视 | 图生 3D 主输入 + 项目内当概念图 |
| B 侧图 | 正侧视（偏航 90°，俯角 15°） | 修正进深比例，防"纸片建筑" |
| C 背图（选做） | 背 3/4 视 | 有院墙/后门的建筑才需要 |

### 统一提示词骨架（每座只替换第一个括号）

```
中国三国时期 {建筑名}，{一句话功能描述}，
3/4 俯视视角（俯角 30°，偏航 45°），正面朝向镜头，
干净半写实风格，帝国时代4 质感，
木构架 + 青瓦坡屋顶 + 夯土台基，{该建筑专属特征}，
正面与右侧面同时可见，进深与开间比例 1:1，
无地面、无阴影、无边框、无文字、无人物，
纯白背景，居中等比，1024×1024
```

### 生图阶段的四条纪律

1. **绝对不要画落地阴影**——引擎会投真实阴影，两套阴影方向必然打架
2. **允许画水平台基**——倾斜后正好压住地形接缝
3. **光向固定左上受光**——对齐 `SUN_EULER_DEG = (-55°, 45°, 0)`
4. **一次只调一个变量**——换风格先在一座建筑上试，别一次改 28 座

## 七、阶段 3：图生 3D

| 设置项 | 值 |
|---|---|
| 输入 | A 主图 + B 侧图（多视图模式） |
| 生成质量 | 最高档（面数不限，AI 通常给 10~50 万面） |
| 对称 | 开（建筑基本都是左右对称） |
| 贴图生成 | 开，1024~2048 |
| 输出格式 | .glb |

**不要**在生成器里直接设目标面数。生成器自带的减面算法比 Blender 的 Decimate 差，会把直角削圆、把屋檐拉塌。正确做法：出高模 → Blender 减面。

生成后第一件事：**导入 Blender 量包围盒**，和尺寸表对比。AI 生成的模型尺寸基本不靠谱，要靠数值缩放修正，别靠肉眼。

## 八、阶段 4：减面（Planar 详解）

### Planar 到底在做什么

三角减面（Collapse）是"把顶点往一起捏"，曲面也会被捏平。
Planar 是"把**共面**的三角合并成一个大 n-gon"——只要角度差在阈值内就视为同一个平面。

建筑 80% 的面都是平的墙、平的顶、平的台基，所以 Planar 能砍掉 60~70% 的面，**形状完全不变**。但它对曲面（屋顶的瓦弧、圆形塔身）无效，那部分必须靠 Collapse。

### 方法 A：Decimate 修改器（推荐，建筑用）

1. 导入 glb，选中物体
2. `Ctrl + A` → Scale（应用缩放，必须先做）
3. 右侧属性栏 → 扳手图标 → Add Modifier → Generate → **Decimate**
4. Mode 选 **Planar**
5. **Angle Limit = 5°**（默认是 5，正好；想更狠用 8°，想保细节用 3°）
6. 点修改器下拉菜单 → Apply
7. 检查面数（右下角 Statistics 的 Faces）

### 方法 B：有限融并（更好控 UV）

1. `Tab` 进编辑模式 → `A` 全选
2. 顶部菜单 **网格 → 清理 → 有限融并**
3. 左下角 `F9` 弹出参数：
   - 角度 **5°**
   - **勾选「限定」→ UV 接缝**（这一步很关键，否则 UV 会被揉烂）
4. 确定

> 两个方法效果几乎一样。方法 B 因为能"按 UV 接缝保留"更安全，建议第一次先用 B 跑一座看看。

### 完整减面顺序（建筑）

```
AI 高模（5 万面）
   ↓ Planar 5°         → 约 8000 面，形状不变
   ↓ Collapse 到目标值  → 6000 面，只削曲面细节
   ↓ 三角化 + 自动平滑 30°
   ↓ 交付
```

**顺序不能反。** 先 Collapse 再 Planar，会把本该保留的直角也捏斜。

### UV 注意事项

- Planar 会把多个三角合成一个 n-gon，导出 glTF 时自动三角化，**UV 本身不会丢**
- 但如果 n-gon 跨了 UV 接缝，会出现贴图错位 → 用方法 B 勾选 UV 限定规避
- 建筑只需要"大致正确"的 UV（木纹、瓦纹方向对），不用像素级精准

### 单位不要用 Planar

士兵和武将满身曲面，Planar 会削掉轮廓。单位走另一条：

```
AI 高模 → Quad Remesher 重拓扑（四边面）→ 手动修边 → 绑骨
```

面数靠重拓扑控制，不用 Decimate。

## 九、关于「要不要再做一版低模」

老板这个问题的答案分两类，结论不一样：

| 资产 | 要做低模吗 | 原因 |
|---|---|---|
| **建筑** | **不要** | 同屏建筑最多 30~40 座，且是静态的。一档 LOD 完全够用，做低模纯属浪费工时 |
| **单位** | **要，做 2 档** | 同屏 200+，且带骨骼动画，这才是真正的性能消耗点 |
| **树 / 石头** | 不要低模，用 MultiMesh | 同一个 mesh 批量实例化，GPU 一次画完 |
| **城墙** | 不要 | 单段 120 面，已经是最低了 |

### 单位 LOD 方案

| 档位 | 面数 | 触发距离 | 做法 |
|---|---|---|---|
| LOD0 | 1500 | 0~25 m | 手工模型 |
| LOD1 | 500 | 25~60 m | 复制 → Collapse 到 35% |
| LOD2 | 80 或改用交叉面片 | 60 m+ | 远景一张 billboard |

Godot 4 在 glTF 导入面板里有 **Generate LODs** 开关，开启后引擎自动按面数比例生成，可以不用手搓 LOD1/LOD2。先开这个，效果不满意再手工。

### 「地面」要不要单独做

**不要。** 两种情况都没必要：

1. **建筑台基**：做进建筑 mesh 里（一体），高度 0.2~0.6 m，底部故意下沉 5 cm 埋进地形，用来遮接缝
2. **地表**：由项目里的地形系统 + splat 贴图提供，模型一律不带地面片

模型里带一块地面片的后果：和地形 Z-fighting、边缘露边、阴影穿帮、每座建筑都要对齐高度。这是新手最常见的返工点。

## 十、阶段 5：清理（每座必做）

| 检查项 | 标准 |
|---|---|
| 缩放 | `Ctrl+A` 应用为 1.0 |
| 原点 | 台基底面中心 → `右键 → 设置原点 → 3D 游标` |
| 朝向 | 正面朝 -Z（Blender 里即 -Y） |
| 法线 | 全选 → `Shift+N` 重算外向 |
| 平滑 | 右键 → Shade Auto Smooth，**30°**（直角保持硬边） |
| 重复点 | 编辑模式 `M → 按距离` 合并 0.001 |
| 材质 | ≤ 2 个槽，贴图打包进 glb |
| 命名 | `bld_{id}.glb` |

## 十一、阶段 6：Godot 导入验证

1. 拖入 `assets/models/`，导入面板确认 **Generate LODs** 按需开
2. 场景里实例化，放一个 2 m 的参考立方体在旁边
3. 逐项核对：
   - 底座宽 = 格数 × 2.0 m
   - 总高 = 尺寸表值
   - 贴地：原点在地面 y=0
   - 正面朝相机初始方向
4. 开游戏跑一次，看它和现有地形/兵种的比例是否协调
