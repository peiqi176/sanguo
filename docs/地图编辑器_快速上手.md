## 2. 三种模式（同一颗左键，干不同的事）

编辑器左上角有模式提示。三种模式靠**进入方式**切换，不靠猜：

| 模式 | 怎么进 | 左键做什么 |
|---|---|---|
| **地形**（默认） | 按 `1/2/3/4` 或 `Esc` | 用笔刷涂抹地形 |
| **放置** | 右侧调色板点任意条目 | 把选中的东西落到光标处 |
| **选择** | 按 `V`，或点调色板右上「选择」 | 点中已有对象 |

## 3. 完整操作表

| 操作 | 说明 |
|---|---|
| **左键拖动** | 地形模式下用笔刷涂抹（⚠️ **先按 1~8 选中笔刷才生效**，默认"空手"只弹提示） |
| **1 / 2 / 3 / 4** | 抬升 / 下压 / 平滑 / 平台（同时切回地形模式） |
| **5 / 6 / 7 / 8** | 切换**贴图层**：5=沙地 6=泥土 7=裸岩 8=林地表（切到哪层，笔刷刷的就是哪层） |
| **V** | 选择模式 |
| **Esc** | 退出当前模式，回到地形模式并**取消已选笔刷**（回到空手） |
| **右键** | 放置模式=取消放置；选择模式=取消选中 |
| **Delete** | 删除选中的对象 |
| **WASD** | 平移相机 |
| **Q / E** | 旋转（勾「锁定相机朝向」后锁死，2.5D 预览用） |
| **滚轮** | 缩放（视角已锁定：俯角 45° / 偏航 45°，不再随鼠标转） |
| **Ctrl+Z / Ctrl+Y** | 撤销 / 重做**地形**（32 步） |
| **Ctrl+S** | 保存 |
| **F5** | 保存并试玩 |

左面板还能调：笔刷半径、笔刷强度、**绘制阵营**（放建筑/单位时写进地图的归属）。

### 贴图层（拼图 / splat）

按 `5/6/7/8` 或点左栏「沙地 / 泥土 / 岩石 / 林地」按钮选中要刷的层，然后**照常左键涂抹**——
刷的是颜色层，不改高度，所以可以放心在山坡、河滩上画。四个通道是叠加关系：
刷过的权重越大，该层贴图越显；没刷过的地方保持程序生成的草地/岩石分布。
**按住 Shift 拖动 = 擦除**（把刷过的地方擦回程序生成的默认地表）。
左上角模式标签会显示当前层（如「笔刷：地表·沙地（Shift=擦除）」）。
贴图层**随 Ctrl+S 一起保存**（地图目录下的 `splat.png`），F5 试玩同样生效，
撤销/重做对贴图层同样有效。

## 4. 放置对象

右侧是**调色板**，七个分类：建筑 / 单位 / 资源 / 装饰 / 村庄 / 野马 / **未注册**。

1. 点分类按钮（如「建筑」）
2. 点列表里的条目（如「官府」）→ 进入放置模式
3. 鼠标移动时会出现**半透明预览 + 绿色占地格**
   - 绿色 = 能放；**红色 = 放不下**（越界 / 压到别的建筑 / 在水里）
4. 左键落位，可以连续放；右键或 Esc 退出

**光标对准的是建筑中心**，不是左上角 —— 3×3 的官府会自动往左上偏移一格半，所见即所得。

### 选中与修改

按 `V` 进选择模式，点中一个对象，右侧出现**检查器**：

- 看：类型、id、格子坐标
- 改**归属**（蜀/魏/吴/中立）—— 建筑的阵营色会立刻重画
- 改**资源量**（只对普通资源点有效；矿洞是无限量，不显示）
- **删除**

## 5. 导入一张新贴图（M3）

三个入口，效果一样：

| 入口 | 操作 |
|---|---|
| **拖拽** | 从资源管理器把 PNG **拖进编辑器窗口** |
| **按钮** | 调色板右上角 **「＋图」** → 选文件 |
| **未注册** | 调色板第 7 个分类 **「未注册」** 里那些灰显的图，点一下 |

点了以后弹出导入窗口，三步：

1. **看校验结论**（红=不能导，黄=能导但建议改）
2. **选分类**（建筑/单位/武将/资源点/村庄/野马/辎重车）
3. **填实体 id**（小写字母+数字+下划线，如 `warehouse`）→ 点「导入并注册」

导入成功后：文件拷进 `assets/sprites/`、`config/asset_map.json` 写入一条、
调色板自动跳到对应分类 —— **不用重启编辑器**就能摆。

### 校验会拦什么、提醒什么

| 级别 | 项目 |
|---|---|
| ✖ 拦下 | 文件不存在 / 解不开 / 完全透明 / 最短边 < 32 / 最长边 > 4096 / id 非小写字母数字下划线 |
| ⚠ 提醒 | 不是正方形 / 没有透明通道 / 底边留白 > 25% / 内容高度 < 画布 8% |

「底边留白」是这里最值得看的一条：留白太大通常意味着这张图画歪了、
或者底部带了一条不该有的投影。**游戏会自动把内容底边贴到地面**，
所以留白大不会导致浮空，只是说明这张图本身的比例可能不对。

### 5.1 进阶：一次性导入「建筑 / 兵种」

「＋图」只管贴图 —— 它能给**已有**实体换张画，但改不了这个实体是谁。
想从零造一个新建筑 / 新兵种，用调色板右上角的 **「＋实体」**。

两者差别一句话：**「＋图」= 换皮，「＋实体」= 造人。**

窗口里填的是这张表：

| 类型 | 字段 |
|---|---|
| 建筑 | 占地宽/深（1~8 格）、血量、建造时间、人口上限、木/粮/金/铁造价 |
| 兵种 | 血量、攻击、防御、移速、攻速、射程、士气、人口、训练时间、木/金造价、**由谁训练** |

「由谁训练」是兵种专有的，默认刀兵营。**不选它，这个兵进游戏后没有任何建筑能造，
只能在地图编辑器里摆着** —— 所以别把它设成"不训练"除非你只要个场景摆件。

导入成功后：

- 贴图 → `assets/sprites/<id>.png`，映射 → `config/asset_map.json`
- 玩法定义 → `config/custom_units.json` 或 `config/custom_buildings.json`
- **内置表 `units.json` / `buildings.json` 一个字节都不动**
- 训练挂载（`train_from`）在内存里注入到对应建筑的 `trains` 列表，磁盘上也不动
- 调色板立刻出现这一项，能摆、能进游戏建/造，不用重启

导入错了：在调色板里选中它 → 点右下 **「删除选中」**。
只删定义和映射，PNG 会留在 `assets/sprites/` 里落到「未注册」分组，可以重新挂。

想彻底回到原厂状态：删掉 `config/custom_units.json` + `custom_buildings.json` 即可。

> 内置 id 不允许覆盖（撞名直接拒绝）。这是故意的 —— 省得"我以为在改自己的建筑，
> 其实把官府的 5000 血改成了 300"。

## 6. 贴地是怎么算的（很重要，影响你以后出图）

以前每张贴图在 `asset_map.json` 里手填一个 `offset_y`（0.5~1.5），
但实测每张图的**内容底边留白**从 0%（内城墙）到 21.3%（农田）不等，两者零相关 ——
结果就是每个兵约 **1/4 的身子埋在地里**，而且埋的深度各不相同。

现在改成量出来：

```
世界高度 = 画布高 × pixel_size × scale
anchor_y = 世界高度/2 − 底边留白(像素) × pixel_size × scale
```

`pixel_size` 保证"世界高度只跟分类参考高 × scale 有关，与你导出多大分辨率无关"。
**所以以后用 Agnes 或任何工具出图，只要满足两条就自动贴地正确：**

1. **透明底**（不透明区域就是要显示的内容）
2. **内容底边贴齐画布底边**（脚底/屋基不要留大块空白）

`offset_y` 仍然保留，但语义变成「在地面之上额外抬升几米」，默认 0。

## 9. 这一版修掉的老 Bug

1. **地形贴图从来没生效** —— `Main._load_terrain_tex()` 里加载 PNG 的代码被整段注释。
2. **水面/最高高度两份来源** —— shader 读常量、`get_height()` 读 params，拖滑块时视觉不跟。
3. **`Sprite3D.shadow_cast` 是 Godot 3 写法** —— Godot 4 叫 `cast_shadow`。
4. **`user://maps/` 被两套不兼容格式共用** —— 老参数图和工坊地图会互相误读。
   现在 `MapSaveManager` 只认 `params.json`、`MapIO` 只认 `map.json`，两边都拒绝删对方的图。
5. **所有精灵都陷在地里** —— `offset_y` 手填值与真实底边留白零相关（见第 6 节）。
6. **★ 所有 2.5D 精灵其实是隐形的** —— 全项目 13 处写了
   `Sprite.transparency = BaseMaterial3D.TRANSPARENCY_ALPHA`。
   Godot 4 里这个 `transparency` 是 **float 淡出值**（0=不透明，1=全透明），
   而 `TRANSPARENCY_ALPHA` 这个枚举**正好等于 1** —— 等于把每个精灵设成 100% 透明。
   于是贴图加载日志全是 `✅`、`is_visible_in_tree()` 也是 `true`，画面上什么都没有。
   删掉之后单位/建筑/血条/村庄/野马/辎重车/建造虚影全部显形。
   截图见 `docs/验证_2.5D单位上屏.png`。
7. **`ResourceLoader.exists()` 对没导入的 PNG 说谎** —— 新图会被判"不存在"而掉到错误目录里找，
   表现成"导入成功了但调色板还是方块"。现在文件在就直接运行时解码。

## 10. 已知限制（这一版明确不做）

| 限制 | 说明 |
|---|---|
| **Ctrl+Z 只撤销地形，不撤销对象操作** | 放置/删除对象目前不可撤销。地形和对象是两套数据，共用一套栈会互相打架，对象撤销要等 M7-4 |
| 建筑不能旋转 | doc 里有 `rot` 字段，但 UI 未开放（旋转会让 footprint 与视觉朝向不一致，要单独处理） |
| 不能拖动已放置的对象 | 目前只能删了重放 |
| 不能框选 / 复制粘贴 | 同上，M7-4 |
| 地形笔刷只有 4 种算子 | 抬升/下压/平滑/平台；**贴图层已做**（5/6/7/8 刷沙/泥/岩/林地），悬崖与道路算子还没做 |
| 没有自动生成向导 UI | 生成器本体已在 M4 落地（命令行/代码调用），编辑器里的向导界面还没做 |
| 导入不自动裁切/缩放 | 有意不做：素材问题要在源文件里修，工具偷偷改会让人对不上账 |
| 建筑/单位还缺 26 张贴图 | 需要先定美术锚点（角度统一）再批量出 |

## 12. 自动生成地图（M4，已可用）

命令行一键生成（会存到 `user://maps/<名字>`，随后游戏主菜单里就能选）：

```bash
# 生成「双雄争霸」并拍全景 + 起点近景到 docs/
godot --path . res://tools/_shot_playable.tscn -- --tpl=two_kingdoms --out=demo
```

五套模板：`three_kingdoms`（三分天下 3 人）/ `two_kingdoms`（双雄争霸 2 人）/
`four_warlords`（四方割据 4 人）/ `central_prize`（中原逐鹿 2 人抢矿）/ `warlord_rush`（群雄并起 8 人）。

只跑管线、不截图：

```gdscript
var MapGenService = preload("res://scripts/mapgen/MapGenService.gd")
var MapTemplates  = preload("res://scripts/mapgen/MapTemplates.gd")
var tpl: Dictionary = MapTemplates.template_def("three_kingdoms")
var r: Dictionary = MapGenService.generate_and_save(tpl, {"map_name": "我的图"})
print(r["text"])     # 7 项校验报告
```

公平性由**结构**保证，不是靠事后比较：只选一半起点，其余由对称轨道翻出来；
每个起点周围的资源用同一张角度表绕自己转；中立富矿压在地图正中（到各家等距）。
